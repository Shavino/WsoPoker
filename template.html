One-time setup

This poker room runs on your own free Google Firebase backend. You only do this once.

  1. Open console.firebase.google.com and click Add project (give it any name, you can skip Analytics).
  2. In the left menu choose Build → Realtime Database, click Create Database, pick a location, and select Start in test mode.
  3. Click the gear ⚙ → Project settings. Under Your apps, click the web icon </> and register an app (any nickname).
  4. Copy the whole firebaseConfig = { … } it shows and paste it below.

Pasting here saves it on this device so you can test right away. To let friends join, put the same config into the file's config block before you host it — see the setup notes that came with this file.
